Agentic Rental Decision Intelligence Platform

Agentic rental evaluation platform that consolidates fragmented housing and neighborhood data into automated property comparison.

PythonLangGraphPostgreSQLGoogle Maps APIFastAPIDocker

Implementation & outcomes

  • Reduced rental evaluation effort by about 80% by consolidating 8+ housing and neighborhood data sources into a decision pipeline.
  • Designed a LangGraph multi-agent workflow with Planner, Retrieval, Reasoning, Verifier, and Recommendation agents.
  • Grounded recommendations in normalized API evidence to reduce hallucinations, combining constraint filters with weighted ranking across 20+ rental signals.
  • Reduced recommendation latency by 65% through parallel API orchestration, semantic caching, and asynchronous FastAPI pipelines.
