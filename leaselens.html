IN PROGRESS

LeaseLens AI

Agentic Rental Decision Intelligence Platform

An agentic rental evaluation platform that consolidates fragmented housing and neighborhood data into automated property comparison. Work in progress.

STACK

Tech stack

  • Python
  • LangGraph
  • PostgreSQL
  • Google Maps API
  • RentCast
  • FastAPI
  • Docker
DESIGN

How it works

  • A LangGraph multi-agent workflow (Planner, Retrieval, Reasoning, Verifier, Recommendation) for stateful task orchestration and evidence-grounded recommendations.
  • Housing and neighborhood data from several sources (Google Maps API, RentCast) normalized into one evidence set in PostgreSQL.
  • Recommendations grounded in that normalized evidence, combining constraint-based filtering with weighted ranking across rental signals, to limit hallucinations.
  • Parallel API orchestration, semantic caching and asynchronous FastAPI pipelines to cut redundant retrieval and LLM calls.
