MaterniFlow

Multi-Agent Clinical Operations System

Clinical operations prototype using a ReAct orchestrator, tool agents, and database safety guardrails.

PythonFastAPIGPT-4 APIPostgreSQLNext.js

Implementation & outcomes

  • Designed a ReAct-based orchestrator that decomposes multi-step clinical requests into GPT-4 function calls.
  • Implemented 3 specialized tool agents with schema-validated parameters.
  • Built guardrail middleware for SQL injection detection, schema validation against a 12-table PostgreSQL model, and surgical slot conflict resolution.
  • Trained a logistic regression model on synthetic OB/GYN admission data and exposed length-of-stay predictions through FastAPI.
