ResponseMatch

LLM Emergency Response Matching System

Multi-agent emergency response matching system built as a follow-up to the Seattle OEM internship.

PythonLangGraphClaude APIChromaDBFastAPI

Implementation & outcomes

  • Architected a multi-agent system automating volunteer matching across 40+ Seattle 311 categories.
  • Parsed heterogeneous request data into urgency, geo-location, and keyword schemas.
  • Designed dual-track validation combining LLM semantic matching with rule-based scoring, reducing false-positive matches by 30% versus an LLM-only baseline.
  • Integrated RAG via ChromaDB grounded on public handbooks and improved RAGAS Faithfulness from 0.62 to 0.84.
