IN PROGRESS

ResponseMatch

LLM Emergency Response Matching System

Matching community service requests (Seattle 311 style) to volunteers, built as a self-initiated follow-up to my Seattle OEM internship. Work in progress.

STACK

Tech stack

  • Python
  • LangGraph
  • DeepSeek
  • ChromaDB
  • FastAPI
BUILT

Built so far

  • A LangGraph workflow that parses each request into urgency, required skills, certifications and languages.
  • Dual-track scoring: rule-based hard constraints (availability, range, certifications, language) run in parallel with an LLM judge grounded in handbook passages retrieved from ChromaDB; volunteers are recommended only where both tracks agree.
  • A pluggable LLM backend (DeepSeek by default, Claude supported), a FastAPI service and an offline test suite.
NEXT

What comes next

  • Ingest public preparedness handbooks and Seattle 311 open data.
  • Build a labelled evaluation set and measure false positives against an LLM-only baseline; then add RAGAS faithfulness.
